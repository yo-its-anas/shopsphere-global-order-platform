# Documentation

Holds architecture, decisions, APIs, operating guides, standards, viva material, and delivery evidence in reviewable source formats.

The [requirements traceability matrix](requirements-traceability.md) maps functional and engineering examination requirements to components, interfaces, test evidence, demonstrations, and an evidence-qualified current status. Significant decisions are indexed under [Architecture Decision Records](adr/README.md), and executable procedures are indexed under [Guides](guides/README.md).
