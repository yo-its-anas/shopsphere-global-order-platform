# Guides

Operational and user guidance for the implemented Customer Identity and Account Management boundary:

- [Installation](installation.md) — prerequisites, configuration boundaries, and non-destructive validation.
- [PoC deployment](deployment.md) — PostgreSQL, Keycloak, and customer-service deployment order and verification.
- [Keycloak administration](keycloak-administration.md) — protected access, realm roles, clients, events, and safe operational practices.
- [Customer self-service](customer-self-service.md) — registration, sign-in, profile, address, activity, and support boundaries.

These guides distinguish implemented repository assets from successful end-to-end evidence. They do not describe the incomplete catalogue, order, analytics, or production platform as operational.
