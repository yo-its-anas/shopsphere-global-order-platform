# Guides

Operational and user guidance for the implemented Customer Identity and Product Catalogue/Inventory boundaries:

- [Installation](installation.md) — prerequisites, configuration boundaries, and non-destructive validation.
- [PoC deployment](deployment.md) — PostgreSQL, Keycloak, Redis, Kafka, customer-service, catalogue-service, and API Gateway deployment order and verification.
- [Keycloak administration](keycloak-administration.md) — protected access, realm roles, clients, events, and safe operational practices.
- [Customer self-service](customer-self-service.md) — registration, sign-in, profile, address, activity, and support boundaries.
- [Catalogue and inventory user guide](catalogue-inventory-user.md) — role-aware product, price, availability and operational inventory workflows.
- [Catalogue and inventory administrator guide](catalogue-inventory-administration.md) — governed product/category/price/stock operations and platform evidence.

These guides distinguish implemented repository assets from successful end-to-end evidence. They do not describe incomplete Order Processing, Analytics, or production recommendations as operational.
